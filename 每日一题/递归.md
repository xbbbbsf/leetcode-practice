递归（Recursion）其实就一句话：**函数自己调用自己。**

它的核心思想是：**“大事化小”**。把一个复杂的大问题，拆解成和原问题一模一样、但规模更小的子问题，直到小到不能再小，直接就能得出答案。

---

### 🧠 最简单的例子：俄罗斯套娃

想象你手里有一个**俄罗斯套娃**，你想知道里面一共有多少层。

你会怎么做？
1.  打开最外面的娃娃，发现里面还有一个小的。
2.  再打开这个小的，里面还有一个更小的。
3.  一直重复这个过程……
4.  直到你打开一个娃娃，发现**里面是实心的，没有娃娃了**。
5.  这时候你就知道：到头了，开始往回数。

这就是递归！
*   **“打开娃娃”** 就是函数在调用自己。
*   **“里面是实心的”** 就是**终止条件**（也叫基线条件），告诉程序该停下来了。

---

### 🧮 数学的例子：算阶乘

如果要用代码实现，最经典的例子是计算 **n 的阶乘**（记作 `n!`）。
比如 `5!` 就是 `5 × 4 × 3 × 2 × 1`。

我们可以这样定义阶乘：
*   **5! = 5 × 4!** （大问题拆解）
*   **4! = 4 × 3!** （继续拆解）
*   ...
*   **1! = 1** （小到不能再小了，这就是**终止条件**）

#### 对应的代码（Python）

```python
def factorial(n):
    # 1. 终止条件（出口）：如果 n 是 1，直接返回 1
    if n == 1:
        return 1
    
    # 2. 递归调用（拆解）：否则，返回 n * (n-1)的阶乘
    else:
        return n * factorial(n - 1)

# 调用一下
print(factorial(5)) 
# 输出结果：120
```

#### 它是怎么跑的？

当你调用 `factorial(5)` 时，程序是这样思考的：

1.  **递推（往下挖）**：
    *   想算 `factorial(5)` -> 发现得先算 `factorial(4)`
    *   想算 `factorial(4)` -> 发现得先算 `factorial(3)`
    *   ...
    *   算到 `factorial(1)` -> **碰到终止条件！** 返回 `1`。

2.  **回归（往回填）**：
    *   `factorial(2)` = 2 × 1 = 2
    *   `factorial(3)` = 3 × 2 = 6
    *   `factorial(4)` = 4 × 6 = 24
    *   `factorial(5)` = 5 × 24 = 120

### ⚠️ 递归的两个必要条件

写递归一定要记住这两点，缺一不可，否则程序会死循环（栈溢出）：

1.  **必须有终止条件**（比如 `n == 1` 时停止）。
2.  **每次调用必须更接近终止条件**（比如 `n-1`，让数字越来越小）。

**总结：递归就是“自己调用自己，直到满足条件停下来，然后把结果一层层带回来”。**
